# DOOMSCROLLR Homebrew Tap

Install the DOOMSCROLLR developer front door with Homebrew:

```bash
brew tap DOOMSCROLLR/tap
brew install doomscrollr
```

Then run:

```bash
doomscrollr
```

This formula installs the npm package [`doomscrollr`](https://www.npmjs.com/package/doomscrollr), which points developers to the DOOMSCROLLR REST SDK, MCP server, and n8n community node.

## Related packages

```bash
npm install doomscrollr
npm install @doomscrollr/api
npm install @doomscrollr/mcp-server
npm install @doomscrollr/n8n-nodes-doomscrollr
```
